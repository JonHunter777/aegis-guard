# Aegis Guard — Security Company Website

Офіційний лендинг охоронної компанії **Aegis Guard**.

## 📁 Структура проєкту

```text
Aegis Guard/
├── assets/                 # Оптимізовані медіа-файли та графічні ресурси
│   ├── business.png        # Охорона бізнесу
│   ├── consultation.png    # Консультація
│   ├── event.png           # Охорона заходів (1)
│   ├── event2.png          # Охорона заходів (2)
│   ├── hero.png            # Головний фоновий банер
│   ├── logo.png            # Логотип бренду
│   ├── monitoring.png      # Моніторинг та відеоспостереження
│   └── personal.png        # Особиста охорона
│
├── css/                    # Стилі та оформлення
│   └── style.css           # Головна таблиця стилів (CSS-змінні, сітка, компоненти, медіа-запити)
│
├── js/                     # Клієнтська логіка та інтерактивність
│   └── main.js             # Меню, фіксація шапки, анімації IntersectionObserver, обробка форми
│
├── index.html              # Основна розмітка сторінки (HTML5, Semantic, SEO-ready)
└── README.md               # Документація проєкту
```

## 🚀 Запуск проєкту
Відкрийте `index.html` у будь-якому сучасному веб-браузері або запустіть локальний HTTP-сервер (наприклад, Live Server у VS Code / IDE).
